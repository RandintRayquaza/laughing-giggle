# @istmx/skills - AI System Design & Rules Engine
> The Elite .cursorrules and CLAUDE.md generator for Cursor, Windsurf, Claude Code, and Gemini.

## What is @istmx/skills?
@istmx/skills (formerly Zenix) solves the biggest problem developers face on r/CursorAI and r/reactjs: relying on the AI to "guess" your project structure, which leads to AI drift, context bloat, and spaghetti UI code.

By injecting a highly structured `.istm-context` directly into your IDE's AI harness (like `.cursorrules` or `CLAUDE.md`), @istmx/skills embraces the **Architect-as-Mentor** workflow. It acts as a dedicated codebase brain, forcing your AI to read deterministic system design blueprints, structured UI tokens, and accessibility contracts before writing a single line of code.

## The CLI Installer
Users initialize the environment by running:
`npx @istmx/skills init`

This installer:
1. Detects the IDE (`.cursor`, `.claude`, `.gemini`, `.cline`).
2. Drops the Master Orchestrator into the root directory.
3. Automatically maps and routes the AI to the `.istm-context/` blueprints.
4. Intercepts raw prompts to build a customized stack architecture.

## The 4 Pillars of Truth
Instead of one massive file that causes compute timeouts, @istmx/skills generates 4 modular context blueprints:
1. `agents.md`: The infinite memory loop and rulebook.
2. `project-overview.md`: Business logic, core features, and domain scope.
3. `architecture.md`: System design, frameworks (Next.js), and APIs.
4. `design.md`: UX strategy, strict token logic, and typography.

## Core Orchestrators (The God Modes)

## Day-to-Day Workflow Skills
- `/istm-craft`: The 1-2 punch workflow. Reads context and architects a feature spec.
- `/istm-develop`: Reads the spec and writes the code.
- `/istm-audit`: Reviews code against the blueprints.
- `/istm-debug`: Root-cause analysis and verifiable bug fixing.
- `/istm-test`: Test generation and coverage validation.

## Architectural Principles
1. **Anti-Slop Validation**: Generic design presets (like "Brutalism" or "Minimal") are banned. The AI must construct bespoke UI utilizing design tokens.
2. **Execution over Blueprints**: Premium skills like `/istm-awwward-designer` physically write code instead of just generating documentation.
3. **Dynamic Documentation Parsing**: Agents scrape URL documentation to override outdated training weights (e.g., bypassing Next.js 16 deprecated methods).
4. **Infinite Memory Loop**: Uses `progress.md` and `error-memory.md` to persist AI state across sessions, ensuring self-healing and task-tracking.
